# Roadster

Open-world 3D driving game in the browser, built with three.js. Drive a flying electric roadster through a Sukkur-inspired city on the Indus at golden hour.

**Play:** https://nadiraliofficial.github.io/roadster/

## Features
- Free-roam city with traffic, villas, pedestrians and Optimus-style robots that react to your car
- Flying electric roadster with folding wheels, thrusters, gull-wing doors, boost, autopilot and battery
- Superchargers, cash pickups, drifting and a 0–60 mph timer
- Sukkur Barrage and a steel arch bridge over the Indus
- Loop test ramp: hit it at 80+ km/h, go upside down and land on all four
- Fly high enough to reach space

## Controls
| Key | Action |
| --- | --- |
| ↑ / ↓ | Gas / brake, reverse |
| ← / → | Steer |
| Space | Handbrake (rise when flying) |
| F | Flight mode |
| Shift / C | Descend |
| B | Boost |
| P | Autopilot |
| T | Glass roof |
| V | Switch car |
| R | Back on road |
| M | Sound |

On phones, on-screen buttons appear.

## Run locally
Open `index.html` in a browser, or serve the folder:

```sh
python3 -m http.server
```
